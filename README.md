# 🏠 HomeDecor Finds

> Small-space decor ideas, smart organization tips, renter-friendly DIY projects, and carefully curated home product recommendations.

**HomeDecor Finds** is a clean, lightweight lifestyle website created for apartment dwellers, renters, and budget-conscious home decorators.

The project combines **human creativity, web development, research, and AI-assisted development** to create a simple and useful home-decor inspiration platform.

# ☁️ Cloudflare Pages Deployment

HomeDecor Finds can be hosted using **Cloudflare Pages** with GitHub integration.

### Deployment flow

```text
GitHub Repository
       ↓
Cloudflare Pages
       ↓
Automatic Deployment
       ↓
Live Website
```

### Basic setup

1. Create a Cloudflare account.
2. Open **Workers & Pages**.
3. Create a new application.
4. Select **Pages**.
5. Connect GitHub.
6. Select the `Home-Decor-Finds` repository.
7. Select the `main` branch.
8. Configure the project as a static HTML website.
9. Deploy the project.
10. Cloudflare provides a `pages.dev` address.

Example:

```text
https://your-project.pages.dev
```

## 🔄 Automatic Updates

The website can automatically update whenever changes are pushed to GitHub.

Example:

```bash
git add .
git commit -m "Update website"
git push
```

The deployment workflow becomes:

```text
Edit Website
     ↓
Commit Changes
     ↓
Push to GitHub
     ↓
Cloudflare Detects Changes
     ↓
Build / Deploy
     ↓
Updated Website
```

This makes it easy to continuously improve the website without manually uploading the website files every time.
